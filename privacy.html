Privacy policy

Effective October 28, 2026. This policy describes the personal desktop utility identified on Google's consent screen as Mockingbird Backups.

Data accessed and purpose

The utility transfers archives selected by its owner to the owner's Google Drive. It uses file contents and metadata to create backups, verify integrity, list its backup objects, and restore selected files. The requested drive.file permission allows access to files created by or explicitly shared with this app; it does not request access to all files in the account.

Storage and sharing

Backup files are stored in the owner's Google Drive. Authorization credentials and verification records are kept on the owner's computer. The utility does not sell data, use it for advertising, or intentionally share backup contents with other users. Google processes the files to provide Drive storage. Publishing this information page does not publish backup files.

Retention and control

Backups remain until the owner removes them. The maintenance utility has no scheduled deletion or synchronization function. The owner can revoke the connection in their Google Account's third-party connections settings. Revocation stops future authorized access but does not itself delete files already stored in Drive. Existing backups can be managed directly in Drive.

Website

This static information website contains no sign-in form, backup browser, advertising, or analytics code. Its hosting provider may process ordinary request metadata to serve it. Never submit credentials or backup contents to this website.

Contact

For questions about this personal connection, use the support address displayed on the Google OAuth consent screen.
